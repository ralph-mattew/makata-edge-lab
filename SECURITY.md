# Security and privacy

## Reporting

Report vulnerabilities privately with GitHub's
[Report a vulnerability](https://github.com/ralph-mattew/makata-edge-lab/security/advisories/new)
form, or by email to edgelab@makata.ai. Please don't open a public issue. The lab is small; the aim
is to acknowledge reports within seven days.

In scope: the Swift package (`Sources/`) and the scripts in `poc/`. Vulnerabilities in llama.cpp,
Core ML, models or other third-party tools should be reported to their maintainers.

## Personal data in results

If you find personal data in a committed file (for example a user name in a path, a device
identifier or a location), report it the same way. It will be removed, and the git history
rewritten if needed.
